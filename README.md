# Chess Audio Learning

200 chess tutorials written for audio narration, organized into 20 learning groups.

The scripts use descriptions of piece relationships instead of board coordinates or move notation. Each lesson includes explanations, examples, and practice questions with answers.

## Start here

- Browse the numbered `.txt` files to read a lesson directly on GitHub.
- Download the repository, extract it, and open `START_HERE_Listening_Guide.html` in a browser for the searchable guide.
- Import one tutorial text file at a time into Audiate or another narration tool.
- Follow the numbered order for the full course, or use the guide to choose a topic.

## Length

The collection contains 492,720 words. Individual tutorials contain 2,402–2,675 words, approximately 16–18 minutes each at 150 words per minute. The full collection is about 54.7 hours at that pace; actual duration depends on narration speed and pauses.

## Topics

Chess fundamentals, thinking habits, tactics, calculation, attacking and defending, minor pieces, pawn structures, rook and queen play, openings, planning, converting advantages, endgames, and practical training.

## Files

- `001_*.txt` through `200_*.txt`: the spoken lesson scripts.
- `START_HERE_Listening_Guide.html`: searchable index, suggested listening paths, and reference notes.
- `collection_manifest.json`: lesson titles, filenames, word counts, and estimated durations.

The original 202 files were copied from the Desktop collection without changing their contents. This README was added for navigating the repository.
