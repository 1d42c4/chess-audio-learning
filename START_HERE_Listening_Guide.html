Using the collection

Start with lesson 001 for a progressive course, or choose a topic below. The three-digit filenames preserve the listening order. Use one TXT file per narration session in Audiate. The text is written to be spoken; this guide and its reference links are separate.

Durations below assume 150 words per minute and do not include extra pauses. For practice questions, pause playback before the answer if you want more thinking time. Listening introduces the ideas; applying one idea in a game and reviewing the result will help it stick.

Examples describe selected relationships so they are understandable by ear. When an example states that there are no other threats, that condition is part of the example. In your own games, check the full position. Strategic guidelines are conditional, and advanced endgame lessons explain plans and conditions rather than reciting move lists.

Suggested listening paths

Build the foundations: lessons 001–020, then 189–190 for the basic rook and queen checkmates. Focus on pawns: lessons 081–100, followed by 161–170. Improve tactics: lessons 021–050, then use 051–070 to connect calculation with attacking and defending. You can return to the full numbered order whenever you like.
